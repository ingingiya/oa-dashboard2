온라인영업팀 업무 가이드

신제품 출시부터 데일리 운영, 채널·광고·행사 관리까지 — 노션에 흩어져 있던 규칙을 업무 흐름 순서로 통합 재정비한 전체 가이드입니다.

00업무 기준 — 한 장 요약

방법은 자율, 기준은 고정. 실행 절차는 아래 각 장 참조. 기준 이탈 = 보고 의무 · 판단이 애매하면 보고가 정답.

매일 유지해야 하는 상태

  • 네이버 가격비교 — 자사가 최저가 (매일 오전)
  • 광고 노출 순위: 원부형 > 상품형 항상 유지
  • 쿠팡 위너 유지
  • N배송 — 전 옵션 재고 있음
  • 리뷰 — 2점 이하 없음

숫자로 고정된 기준

  • 행사 마진율: 기본 30% · 과재고만 20% — 이하 제안 불가
  • 브랜드형 광고 일예산: 3~5만 원 — 급증 시 즉시 점검
  • 발주: 화/목 당일 완결 · 최소발주일 = 1주 평균 +20일
  • 크루특가 제한: 1차 2개 / 2·3차 3개 — 무제한 진행 금지
  • 리뷰 이벤트: 포토리뷰 2,000P · 약 30개 도달 시 종료

Meta 광고 운영 규칙 뷰티팀

성과 판단

  • Meta 표기 ROAS·전환값 불신 → CPA + 네이버 실매출 교차검증
  • 캠페인 평균 X → 세트 단위 모니터링 · 예산 증액은 하루 20~30% 스텝업까지

소재 제작 (새 타겟)

  • 새 타겟 소재 총 10개 = 행사가 5개 + 기본(상시가) 5개
  • 소재 교체는 피로도 높은 소재만 선별 — 전체 갈아엎기 금지 (학습 리셋)

행사 시 운영 — 학습기간 보호

  • 행사 시 세트가 머신러닝 학습기간에 재진입하지 않도록 ON/OFF 관리
  • OFF 후 7일 이내 재가동 필수 — 초과 시 학습 리셋 → 행사↔상시 전환은 7일 내에서만
  • ON/OFF는 수동 X → 대시보드 예약 기능으로 행사 시작/종료 시각 사전 예약

중단 판단

  • 대시보드 [중단검토] 표시 세트는 OFF — 확인 즉시 처리, 판단 필요 시 보고 후

즉시 보고 — 판단하지 말 것

  • 최저가 이탈인데 원인 불명 · 폐쇄몰 의심
  • 광고비 일 지출 급증
  • 2점 이하 리뷰 · CS 이슈성 문의
  • 재고 쇼트 임박 (현재고소진일 기준)
  • 계약·비용·법적 이슈 전부

보고 방식

  • 일간: 이상 없으면 생략 · 이상 시 당일 팀장 1:1 웍스 — 스크린샷 + 원인 후보 + 조치/제안 한 줄
  • 주간: 주간회의 전 담당 지표 추이 공유
  • 평가 연계: 기획안 80% 이상 이행 + 유지 기준 달성률 반영

오전 업무

네이버 쇼핑 가격비교 확인 네이버

  • 원부 매칭 대상: 오아스토어 · 11번가 · 옥션 · 지마켓 · 신세계몰 · SSG · 이마트몰 · 롯데온 · H몰 · GS샵 · 홈앤쇼핑 · 롯데홈쇼핑
  • 매칭 경로: 쇼핑파트너센터 → 브랜드 관리 → 카탈로그 관리 → 일반상품 조회 → 모바일 최저가순 정렬 → 처리내역 조회로 확인
  • ⚠️ 카탈로그는 추가 매칭만 가능, 매칭된 카탈로그 삭제 불가
  • 특정 사이트가 조회에 안 뜨면 → [비밀특가]/[G]특가 등 상품 연동 코드 미등록 → 추가 연동 필요

최저가 이탈 시 대응

  • 옥션·G마켓·11번가 등 관리 가능 오픈마켓: 메일로 해결 
  • 원부매칭 사이트에 쿠폰·할인 부착: 온라인 전략방 공유
  • 쿠팡에 쿠폰·할인 부착: 온라인 전략방 공유 (10시 · 3시) — 쿠팡은 크롤링되므로 쿠폰 붙은 마켓 먼저 해결 (확인 안 되면 폐쇄몰)

네이버 리뷰 확인 네이버

  • 별점 2점 이하 리뷰 확인
  • 상단 인기 제품에 한해 → 온라인영업 좋아요 작업방에 4·5점 리뷰 좋아요 요청 (3페이지까지)- 지금은안함 
  • 단종 예정 상품은 요청 X — 네이버웍스 재고 메일로 단종 예정 파악

판매관리 · 발송기한 초과 확인

  • 스마트스토어 / 11번가 / 이베이 대상

03발주 & 재고 관리

발주 프로세스 (변경 공지) — 발주는 화/목 당일 완결. 부자재 요청은 월/수 (오후까지 가능). 월·수 재고 파일 도착 즉시 발주 필요 건 우선 확인 — 파일 지연·휴가 대비해 미리 체크.

발주 판단 기준

  • 신청 요일: 월·수 / 화·목
  • 최소발주일 탭 → 1주 평균판매량 기준 · 최소발주일 = +20일로 계산
  • 28일 평균과 1주 평균의 갭이 클 경우: 총매출 파일 발주계획탭 → ALL에서 제품명 검색 후 확인
  • 실재고 판단은 쿠팡 제외: (재고 + 생산중 개수) ÷ 평균 판매량 = 남은 개월수
  • 현재고소진일 오름차순 정렬 → 발주번호/예상 쇼트일 전달 · 입고일 타이트한 제품은 별도 전달

풀필먼트 N배송 

  • 매주 월요일 발송 · 금요일 합산 (팀 발송분도 금요일 합산)
  • 계산식: (적재수량 + 기존 아르고재고) ÷ 일평균 판매량 = 판매가능기간
  • 택배박스 여부: 오아팀 구글시트로 필수 확인
  • 카톤수량 과다 제품은 2주치만 택배 발송 → 김현유 팀장님에게 파일 + 메시지로 요청
  • 트럭 = 퀵 · 창고이동 시 수령 필수

네이버 풀필먼트N배송 재고 관리 네이버

  • 풀필먼트 재고 매일 확인 필수 — 옵션 단위 재고 체크
  • ⚠️ 옵션 하나라도 재고 없으면 풀필먼트 N배송 → 판매자N배송으로 전환 (N배송에서는 옵션 하나만 수정 불가 — 예: 소닉플로우 베이지만 품절이어도 전체 전환)
  • 아르고 재고 조회: 재고 → 재고조회 → SKU 기준 — 제품 옵션마다 SKU명으로 검색

① 품절 시 — 풀필먼트 N배송 → 판매자N배송 전환

  • 풀필먼트 '설정안함'으로 변경
  • 재고수량 99,999개 재설정
  • 배송속성: 판매자N배송/ 판매자창고 / 묶음배송 가능 · 택배사 우체국
  • 추가상품 '설정함' · 기본반품택배사 우체국으로 변경
  • 금액이 추가되는 옵션만 '사용안함' 표시 (전체 옵션 X) → 정상 운영 여부 체크

② 입고 후 — 판매자배송 → N배송 원복

  • 일반입고 → 입고완료일 체크 · 입고요청번호 확인 → 추가작업 있으면 이슈 확인, 없으면 정상입고
  • 상세페이지 내 배송: 판매자N배송 → 일반배송 또는 오늘출발 선택 (다음 단계 진행 조건)
  • 풀필먼트 '설정함' → 배송속성 N배송 · 택배사 우체국/한진 고정 (맨윗줄)

③ 상세페이지 표기 일치

  • 배송 방식과 상세페이지 표기를 항상 일치시킬 것 —우체국/한진 고정 (맨윗줄)

부자재 요청 가이드

  • 기존 양식 X → 전산에 있는 상품명·수량으로 간략히 요청
  • 리테일 / 카카오 / 색상 분류 제품은 정확하게 구분해서 요청

단종 · 악성 재고

  • 단종 재고 네이버 단독 판매 시: 본품 옵션 + 추가구매건까지 확인
  • 악성재고(총 판매일수 1년 초과 등): 부장님 요청 시 발송
  • 크롤링 금액 인하: 쿠팡 일일판매 공급가 확인 (상시가 갭) — 현재고는 공급가 조정 X, 추후 입고분부터 조정 가능
  • 쿠팡에서 잘 나가는 제품은 행사를 자주 안 하는 것이 유리

  • 애매할 땐 LIKE '%소닉플로우%' 식 fuzzy 매칭으로 먼저 등록명 확인
-- 월별 판매 추이 (표준 집계 패턴)
SELECT DATE_FORMAT(판매날짜,'%Y-%m') AS 월, 품목명,
       SUM(판매수량) AS 판매수량, SUM(총매출액) AS 매출액
FROM v_daily_sales_detail
WHERE 품목명 IN ('오아소닉플로우','오아에어리소닉드라이기','오아에어리미니')
GROUP BY 월, 품목명 ORDER BY 월;

-- 채널 3분류 (스마트스토어 / 쿠팡 / 기타)
CASE WHEN 매출처명='스마트스토어' THEN '스마트스토어'
     WHEN 매출처명='쿠팡' THEN '쿠팡' ELSE '기타' END
