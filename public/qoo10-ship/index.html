큐텐 발송 준비 (KSE 배대지)

큐텐 주문 파일을 넣으면 전산 업로드 엑셀·작업지시서·KSE 제품 발송 양식을 만들어요. 파일은 이 브라우저 안에서만 처리돼요 (서버로 안 보냄).

⚡ 자동 실행 (오아 맥에서 처리)

누르면 오아 맥이 순서대로 처리해요: 발송예정일 입력 → KSE 주문수집·통관점검·배송접수 → 송장 라벨 PDF → 전산 위탁 주문서 등록 → 마지막 주문에 작업지시서·PDF 첨부. 1분 안에 시작돼요. 맥이 켜져 있고 큐텐·전산이 로그인돼 있어야 해요.

KSE OTP 필요 — 경은님 휴대폰 인증 앱의 6자리를 넣어 주세요 (30초마다 바뀌어요)

    수동으로 할 때 · 1. 큐텐 주문 파일 넣기

    QSM → 배송관리 → 배송요청(상세보기) → 신규주문 숫자 클릭 → 전체주문 엑셀다운 한 파일 (csv·xlsx 모두 가능)

    여기에 파일을 끌어놓거나 클릭
    DeliveryManagement_detail_….csv

    2. 확인

    주황색 줄 = 옵션에서 제품코드를 못 찾은 주문. 코드 칸에 전산 제품코드(예: M0156)를 직접 넣어 주세요.

    3. 파일 받기

    4. 순서

    1. 큐텐 QSM 배송관리 › 배송요청: 택배사 KSE, 수취인·주소·재고 확인 → 발송예정일 입력 (KSE 입고·일본 출고까지 걸리니 넉넉하게, 한 번 넣으면 수정 불가) → 전체주문 엑셀다운 → 위 1번 칸에 넣기
    2. KSE kseoms.com (아이디 oaworld4 · OTP는 경은님 휴대폰 인증 앱) → 배송접수(대기목록) › 주문수집(API): 마켓 qoo10_jp · 계정 큐텐일본 · 상태 배송준비 · 결제일 기간 → 주문서 가져오기(API)
      이미 가져온 주문은 다시 안 들어와요. 장바구니번호·주문번호·상품코드는 바꾸지 마세요 (중복 수집).
    3. KSE 수집된 주문 전체 체크 → 통관이슈예상점검 (1건 약 ¥16,666 초과·상업용 주소 경고) → 이상 없으면 배송접수(국제) → 배송관리 › 팩킹리스트 → 주문 체크 → 바코드 라벨(송장 PDF) 출력
    4. 전산 영업 › 주문 › 위탁 주문서 등록 › 등록: 내용 YYMMDD_큐텐 발주 · 매출처 큐텐 [795-81-01033] · 정산명 이베이재팬 유한회사(큐텐) → 기본값 클릭 → ① 파일 업로드 → 등록 → 확인창 저장
      주문상품 칸은 [M0156]오아아이케어-화이트 형식이어야 전산이 상품을 찾아요 (① 파일은 이미 이 형식).
    5. 전산 영업 › 주문 › 위탁 주문: 주문번호(B26…) ↔ 업체주문번호(큐텐 주문번호)·금액 맞는지 확인 → 목록 맨 위(마지막) 주문 한 건을 열어 주문 관련 파일 › 추가로 ② 작업지시서 + KSE 송장 PDF → 저장 (작업지시서 "우리 전산 이미지" 칸은 이 목록 캡처로 바꿔도 돼요). 송장 상태가 "배송 보류 [업체보류]" → "송장 신청"으로 바뀌면 창고 접수 완료
    6. 창고: 본품에 일본 송장(KSE 바코드), 아웃박스에 국내 송장 → 큰 박스에 모아 양산 KSE 물류센터로 국내 택배
    7. KSE 실제 발송 후에만 → 발송한 주문 체크 › 송장번호 전송 → 큐텐이 배송중으로 바뀌고 고객에게 안내 메일. QSM 배송중 탭에서 추적되는지 확인
      ⚠ 실제 발송 전에 송장 전송(발송처리)하면 판매정지 등 페널티
