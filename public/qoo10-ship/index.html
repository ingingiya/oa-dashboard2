큐텐 발송 준비 (KSE 배대지)

큐텐 주문 파일을 넣으면 전산 업로드 엑셀·작업지시서·KSE 제품 발송 양식을 만들어요. 파일은 이 브라우저 안에서만 처리돼요 (서버로 안 보냄).

1. 큐텐 주문 파일 넣기

QSM → 배송관리 → 배송요청(상세보기) → 신규주문 숫자 클릭 → 전체주문 엑셀다운 한 파일 (csv·xlsx 모두 가능)

여기에 파일을 끌어놓거나 클릭
DeliveryManagement_detail_….csv

2. 확인

주황색 줄 = 옵션에서 제품코드를 못 찾은 주문. 코드 칸에 전산 제품코드(예: M0156)를 직접 넣어 주세요.

3. 파일 받기

4. 순서

  1. 전산 영업 › 주문 › 위탁 주문서 등록 › 등록
    내용 YYMMDD_큐텐 발주 · 매출처 큐텐 · 정산명 이베이재팬 유한회사(큐텐) → 기본값 클릭 → ① 파일 업로드 → 등록
  2. KSE kseoms.com (아이디 oaworld · OTP는 동욱님 인증 앱) → 배송접수 › 주문수집(API) → 오늘 주문 접수 → 배송관리 › 팩킹리스트에서 송장 PDF(A3) 출력
  3. 전산 위탁 주문 목록 캡처 → 작업지시서 "우리 전산 이미지" 칸에 붙이기 (② 파일엔 주문 요약표가 임시로 들어가 있어요)
  4. 창고에 ② 작업지시서 + KSE 송장 PDF 전달 → 본품에 일본 송장, 아웃박스에 국내 송장 부착 → 양산 KSE 배대지로 발송
  5. 큐텐 송장번호는 KSE가 큐텐에 자동으로 넣어요 (택배사 KSE 연동)
