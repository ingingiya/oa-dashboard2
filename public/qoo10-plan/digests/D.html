매출 방정식과 Qoo10 매출 만들기 팁 (JP 2023-05-09 / KO 2024-12-20)

https://article-university.qoo10.jp/entry/06 https://article-university.qoo10.jp/entry/108
  • 매출 = 조회수(방문수) × 전환율 × 객단가. 조회수의 기본은 취급 상품 수 늘리기(상품 페이지 유입 1위 경로는 검색 → 등록 상품이 많을수록 검색 대상 증가). "팔릴지 판단하지 말고 일단 등록".
  • 구매자층: 10~30대 약 70%, 여성 76%(JP판) / 78%(KO판). 타 몰에서 30대+ 남성 타깃이던 셀러가 젊은 여성용 세트로 바꿔 매출 상승 사례, 타 몰에서 화이트/블랙이 잘 팔리는 상품도 Qoo10에서는 핑크를 썸네일·상품명에 내세워 히트한 사례.
  • 메가할인: 연 4회, 대상 상품 20% 할인, 카와구치 하루나 CM·시부야/도톤보리 옥외광고. 메가포: 다음 구매용 포인트 환원으로 재구매율 제고. 그 외 매월 첫째 주 이벤트 개최. 카트쿠폰 조건은 며칠 단위로 바뀌며, 다음 달 이벤트·카트쿠폰 일정은 QSM 공지사항에서 확인.
  • (KO판 추가) 목표 설정 예: 월 100만엔 → 주 25만엔 → 일 3만엔; 상품별 역산(A+B 60만, C 할인 20만, 카트쿠폰 조건 상품 D·E 20만). 전환율 4%·객단가 2,000엔이면 100만엔에 필요한 조회수 = 12,500회.
  • (KO판 추가) 셀러 등급 3단계(일반·우수·파워). 파워셀러는 배송완료 후 5일 뒤 수요일 정산 + 샵에 파워셀러 마크 표시 → CVR 상승.
  • (KO판 추가) 입구 상품·강화 상품 선정 시 참고: 랭킹은 1시간마다 갱신, 카테고리별 200개 상품의 현재 판매가·누적 주문 건수 확인 가능. 인기 키워드는 JQSM 프로모션 ▶ 플러스 전시 ▶ 인기 키워드 보기(카테고리별 주간 평균/전일 검색 수, 급상승 키워드).
  • OA 적용: 일 10건 목표를 역산하면 객단가 ¥3,950 기준 CVR 2%면 일 500 PV, 4%면 250 PV 필요(이건 공식 적용, 원문 수치 아님). 50개 등록 상품을 더 늘리는 것이 조회수의 가장 기본 레버. 핑크 컬러 옵션이 있는 제품(프리온 핑크 등)은 썸네일·상품명에 핑크를 전면 배치.

히트 상품을 만드는 시장 분석 3가지 (JP 2023-08-02 / KO 2024-12-12)

https://article-university.qoo10.jp/entry/28 https://article-university.qoo10.jp/entry/104
  • ① 랭킹 탭 → 내 메인 카테고리 1~100위 판매가를 엑셀에 넣고 합계·평균·중앙값 계산, 평상시/이벤트시 각각. 집계 당시: 평상시 평균 3,362엔·중앙값 1,830엔 / 이벤트시 평균 4,229엔·중앙값 2,764엔(참고치). 중앙값 가격대를 의식한 상품 기획 권장.
  • ② 빅워드 검색 → "리뷰 많은 순" 정렬 → 벤치마크 상품 리뷰 최신순으로 3개월 리뷰 수 확인. 매출 규모 = 3개월 리뷰 수 ÷ 30% × 판매가 (Qoo10은 주문의 약 30%가 리뷰 작성). 3개월인 이유 = 메가할인 1회가 포함되기 때문. 광고비 가늠에 활용.
  • ③ 검색량은 QSM → 프로모션 → 플러스 전시 → 키워드 검색. 예: 프라이팬 1일 약 500건 미만, 홈/생활 카테고리 내 검색 22위. 1일 300건 ≈ 월 1만 건이면 검색형 광고(플러스 전시(키워드)·파워랭크업·스마트세일즈) 적극 활용. 1일 수십 건이면 충동구매형 타임세일 광고, 특히 3,000엔 이하 가격대와 궁합.
  • 무료 검색 대책 선행: "검색 키워드" 란에 10개까지 무료 입력. Qoo10 검색 대상 = 상품명·검색어·브랜드·카테고리. 하반기 상품 페이지 유입 그래프에서 자연검색 + 검색계 광고(파워랭크업·플러스전시·스마트세일)가 상위.
  • OA 적용: 우리 상품(¥3,950 안팎)은 평상시 중앙값(1,830엔)보다 높고 이벤트 중앙값(2,764엔)대 → 메가할인 때 더 잘 맞는 가격대. 경쟁 히터 뷰러·미니 마사지건의 3개월 리뷰 수÷0.3으로 시장 규모를 먼저 계산할 것.

히트 상품을 만드는 경쟁사 분석 3가지 (JP 2023-08-24 / KO 2024-06-19)

https://article-university.qoo10.jp/entry/33 https://article-university.qoo10.jp/entry/79
  • ① 포지셔닝 맵(가격·기능 축) + 체크리스트(가격·할인 유무·Shop쿠폰 유무·배송비·배송). 프라이팬 예: 단품·5점 세트는 경쟁 적음, 13점 세트가 볼륨존.
  • ② 리뷰 철저 확인: 좋은 점(손잡이 분리·수납·선물용)과 불만(테플론 코팅/마감)을 페이지 개선에 반영한 샵이 매출 증가.
  • ③ 경쟁 상품의 검색 표시 순위·특집 페이지 게재 빈도로 마케팅력 파악. 파워랭크업 = 1일 100엔, 표시 순위는 페이지 랭크(최근 판매 건수·리뷰·발송 속도)에 좌우. 1일 수백 건 검색 키워드는 플러스 전시(키워드)로 상위 10위 내 노출 테스트. 경쟁사가 광고를 많이 쓰면 경쟁 상품 페이지 안에 내 상품이 노출되는 스마트세일즈 권장.
  • OA 적용: 일본 히터 뷰러·구강세정기 상위 셀러 페이지에 스마트세일즈를 걸어 경쟁 트래픽을 가로채는 것이 소형 브랜드에 가장 현실적인 광고 진입점.

의외로 모르는 판매 데이터 분석·활용법 (JP 2023-10-18 / KO 2024-12-20)

https://article-university.qoo10.jp/entry/38 https://article-university.qoo10.jp/entry/107
  • Qoo10 Analytics → 요약: 기본 조회 기간 14일. 검색어 Top10으로 SEO 대상 키워드 선정. 예(JP): 내 샵에서 "ワイヤレスイヤホン" 2주 187회 = 일 약 13회 ↔ 플러스 전시 "키워드별 입찰" → "인기 키워드 보기"에서 Qoo10 전체 1일 1,215회(주간 평균), 전일 678회. 예(KO): "iphone16ケース" 2주 923회 = 일 약 66회 ↔ 전체 296회/일, 전일 364회. 전체 대비 내 샵 유입이 작으면 SEO 여지 큼.
  • SEO = 상품명·검색어 적절 입력 + 카테고리·브랜드 등록, 여기에 플러스 전시·파워랭크업·스마트세일즈로 부스트.
  • 유입/전환(트래픽/컨버전) 메뉴: 하단 리스트를 "날짜별"→"상품별"로 바꾸고 "검색결과와 프로모션 페이지 경로 상세 표시" 체크 → 프로모션별 유입 수. 엑셀 다운로드 후 상품번호로 날짜별 CVR 확인.
  • 상품별 CVR 간편 확인: QSM → 상품관리 → 상품 조회/수정 → 리스트 맨 오른쪽에 지난주·어제·오늘의 판매수·PV. CVR = 판매수 ÷ PV.
  • OA 적용: oaworld 50개 상품을 상품 조회/수정에서 PV·판매수로 한 번에 훑어 "PV는 있는데 안 팔리는" 상품(페이지/가격 문제)과 "PV 자체가 없는" 상품(SEO 문제)을 분리.

타 몰(라쿠텐·야후·아마존) 상품 데이터 일괄 변환 등록 (JP 2023-11-29 / KO 2025-09-15)

매출이 달라지는 판매 분석 툴(Qoo10 Analytics) 효과적 활용법 (JP 2023-12-11 / KO 2025-09-14)

https://article-university.qoo10.jp/entry/53 https://article-university.qoo10.jp/entry/147
  • "감으로 광고 집행"(일단 키워드플러스·파워랭크업, 신상품은 타임세일 프리미엄) 경고. 접근: QSM 좌측 "Analytics" → 별도 화면.
  • 요약 화면: 기본 전일부터 과거 14일 수주 데이터, "이전 기간 대비" % 자동 표시(예: 8/30~9/12 검색 → 8/15~8/29와 비교). 톱니바퀴로 비교 기간 변경 → 이번 메가할인 vs 지난 메가할인 비교에 활용.
  • 수주(거래) 현황 그래프: 날짜별/상품별, 우측 상단 "비교 데이터"로 상품 PV·전환율과 겹쳐 보기.
  • 상품 Top10(거래금액/수량/PV)·검색어 Top10. 검색어 예: 무선 이어폰 2주 187회 = 일 13회 vs 전체 1,215회/일(전일 678회).
  • 하단 "샵 데이터"(샵 PV·신규 팔로워) + "구매 고객 수"(신규 vs 재구매 구성). 재구매율 높은 상품에 세일가 → LTV 투자. 소모품·식품은 재구매 비중 높아 "일단 한 번 써보게" 최우선.
  • Shop쿠폰 조건을 "즐겨찾기(팔로우)한 고객"으로 설정 → 팔로워 증가 → 주 1회 쿠폰 안내 발송(쿠폰 Push) 가능.
  • OA 적용: 팔로워 8명 → 팔로워 한정 Shop쿠폰을 띄워 팔로워를 먼저 늘리고, 주 1회 쿠폰 Push를 재방문 채널로 삼을 것. 메가할인 전후 비교는 톱니바퀴 기간 변경으로.

  • 일본 중소 EC 사업자 AI 채택률 16%(라쿠텐 2025.1 조사). EC×생성AI 시장 2025년 약 10.4억 달러 → 2026년 12.4억 달러, CAGR 18.8%(GII).
  • 상품 설명문 생성 시간 1/8~1/10(약 3분/건), 어패럴 대기업 주 5일 → 2~3일, 잔업 30% 감소(ecbeing). ChatGPT/Claude 무료~월 $20.
  • 이미지: Canva AI·Photoroom으로 배경 교체·컬러 배리에이션 → 모바일 썸네일 CTR, 메가할인 배너풍 썸네일 + 키워드플러스 조합.
  • Analytics CSV(PV·수주수량·광고비) → 개인정보 삭제 후 AI 분석. 지표: CV율 = 수주상품수량 ÷ PV × 100, ROAS = 광고 경유 매출 ÷ 광고비. 제안엔 타임세일·Single One 광고 등 구체 시책명 포함.
  • 트렌드: AI 쇼핑 에이전트(OpenAI Instant Checkout·Google Shop with AI Mode) → 상품명·설명에 AI 검색 대응 키워드 선반영. 라이브커머스(ショショショー·Brand LIVE·Qoo10 라이브쇼핑).
  • 모바일 구매 97% 이상 재확인.
  • OA 적용: 우리가 이미 하는 방식(Claude·Comfy 소재)이 그대로 권장안. 50개 상품 일본어 설명문을 AI 검색 대응 키워드 기준으로 재작성하고, ROAS 컬럼을 추가해 광고 판단.

우리 카테고리(미용·건강가전)에 직접 관련된 데이터


플랫폼 규모·고객
  • 회원 2,300만+(2023) → 2,400만(2024), 셀러샵 19,000개, 상품 12억 개, 월 PV 5.4억 건
  • 여성 약 76~80%, 10~30대 약 70%, Z세대 남성 급증
  • 유통총액 연 20~30% 성장(일본 EC 전체 약 5.4%, 다른 기사에서는 약 9%)
  • 구매의 97% 이상이 앱/모바일, 검색결과 상품명은 선두 30자
카테고리 포지션
  • 뷰티·화장품 수수료 10%, 가전·PC·게임 8~10%(이미용가전은 둘 중 하나) + 해외 셀러 +2%(일본 외 계좌/출고지) + 메가할인 이용료 +1% + 외부광고 경유 +1%, 예약판매 +2%
  • 사업자등록번호 등록한 한국 셀러는 수수료 부가세(10%) 면제
  • "식품·일용품·가전·모바일에서 블루오션 찾는 기업"에 Qoo10 추천 명시, 가전 카테고리 "눈에 띄게 성장"
  • 성공 사례로 언급된 한국 브랜드: 마녀공장(뷰티, 메가할인 한정 상품·시즌별 디자인 변경), KUNDAL(헤어케어, 상단 배너), SLIMPLANET(건강식품, 3+1/2+1), SixKShop(K-POP)
  • 타 몰에서 화이트/블랙이 팔리는 상품도 Qoo10에선 핑크 전면 배치로 히트
가격대
  • 랭킹 1~100위 평상시 평균 3,362엔·중앙값 1,830엔 / 이벤트시 평균 4,229엔·중앙값 2,764엔
  • 카트쿠폰 빈발 조건: 3,000엔 10%, 1만엔 이상 — 상품가 기준(배송비 제외)
  • 3,000엔 이하 상품은 타임세일과 궁합, 1일 수십 건 검색 키워드는 타임세일(충동구매형), 1일 300건(월 1만) 이상은 검색형 광고
리뷰
  • 주문의 약 30%가 리뷰 작성(정확 예: 7,816건 중 2,297건 = 29.3%)
  • 매출 규모 추정 = 3개월 리뷰 수 ÷ 0.3 × 판매가
  • 앱에서는 리뷰 총수 대신 평균 평점만 표시 → 평점 관리·빠른 배송
  • 조건부 특전(피드백 혜택)으로 리뷰 Q포인트, 사진 리뷰 선택 가능
  • 경쟁 인기 상품 리뷰 1,000건 이상 읽기
전환·트래픽 벤치마크
  • 온라인몰 평균 구매전환율 약 2%
  • 예시: 전환율 4%·객단가 2,000엔 → 월 100만엔에 조회수 12,500회
  • 판매수 비슷(71 vs 60)해도 PV 3배 차이 = 전환율 차이 → 상품별 PV 확인 필수
  • 유입 채널 16종, 2024년 7월부터 홈 내 세부 유입(타임세일·랭킹) 식별
  • 키워드플러스 상위 노출 최대 16개 상품
광고 단가
  • 파워랭크업·키워드플러스 1일 100엔~, 타임세일 1일 2,000~6,000엔, 스마트세일즈는 주문 체결 시 셀러 설정 수수료율 차감(Qcash 아님)
  • 타임세일·오늘의 특가 프리미엄 슬롯은 게재 중 상품 교체 가능
이벤트
  • 메가할인 연 4회·20%(절반 Qoo10 부담), 기간 중 2,000만 명+ 유입, 2024 3Q 재구매율 64%, 키워드 검색량 +202%
  • 메가포 10% 쿠폰+10% 포인트, 2024 3Q 매출 +248%, 주문의 78%가 대상 상품
  • 매월 첫째 주 이벤트, 다음 달 이벤트·카트쿠폰 일정은 QSM 공지사항
  • 샵쿠폰은 메가 기간 다른 쿠폰과 중복 가능, 팔로워 한정 샵쿠폰 → 주 1회 쿠폰 Push
QSM/Analytics 메뉴 치트시트
  • 검색량: JQSM 프로모션 → 플러스 전시 → 키워드별 입찰 / 인기 키워드 보기(주간 평균/일, 전일, 급상승)
  • 상품별 오늘 PV·판매수: JQSM 상품관리 → 상품 조회/수정 → 검색(CVR = 판매수 ÷ PV)
  • 상품별 유입 경로: Analytics 유입/전환 → 상품별 → "홈·검색결과·프로모션 경로 상세 표시"(과거 2년)
  • 위시·장바구니 추가 고객 수: Analytics 고객현황 → 상품별(전일까지)
  • 전년 동월 상품별 매출: Analytics 거래현황 → 2년 전 같은 달 1일부터
  • 메가할인 전후 비교: 요약 톱니바퀴로 비교 기간 변경
  • 랭킹: 1시간 갱신, 카테고리별 200개(판매가·누적 주문)
  • 카테고리 담당자: QSM 기본정보 → My정보
AI 활용
  • 일본 중소 EC AI 채택률 16%(2025.1), 상품 설명문 작성 1/8~1/10 단축, ChatGPT 무료 업로드 1일 3회, 분석 지표 CV율·ROAS
