오아에 바로 적용할 것

1. Q스페셜 기획전을 샵 메인으로 설정 — 프로모션 > Q스페셜 스튜디오(또는 기본정보 > 셀러샵 관리 > 기획전 관리). 샵 메인으로 두면 샵쿠폰 다운로드 버튼이 최상단 강조, 주목 상품 6~30개 지정 가능. 지금 oaworld 50상품 중 "밀 제품"만 모아 메인 노출.

2. Q스페셜 필수 세팅 디테일 — 배너 1440×676px·30KB 이하 / "상품 상세·셀러샵 표시 조건 = 예" / 모바일 이미지는 1:1 또는 세로가 더 길게 / 이미지 삽입 후 반드시 가운데 정렬 / 서브 테마 미설정 시 상품이 안 뜬다 / 서브테마 우선순위 1,2로 배열. 검색 태그·슬라이드쇼는 생략 가능.

3. 조회수 높은 상품 헤더에 기획전 배너 연결 — 메인 상품 조회 → 기획전 → 다른 상품으로 유입 전파. 오아는 조회 1~2위 상품(히트아이롱 등)에 걸 것.

4. Analytics ES 유입·전환 메뉴로 광고별 효율 점검 — 하단 "자세히 보기"에서 키워드플러스/파워랭크업/타임세일 광고별·상품별 전환 수치 확인. 매주 50상품 중 전환 나는 것만 광고 집중.

5. 신규 단계 광고 조합 = 파워랭크업 + 스마트세일즈(성과보수형, 매출 날 때만 과금). 주력 상품 미확정 상태(=오아)에서 "어떤 광고에 반응하는지 테스트" 용도. 키워드플러스는 메가와리·인기 키워드 때 낙찰가 오르니 자리 잡은 뒤.

6. 메가와리·메가포 기간 중 추가 광고 — 주목 브랜드 애드(앱 메인 중단, 동영상 가능, 2025년 4월 출시)·뷰티 브랜드 애드(검색/카테고리 페이지, CPM 과금, 5월 출시). 타임세일은 검색 결과에도 노출 로직 강화 중.

7. 세트 구성은 "기획 세트"가 랭킹을 먹는다 — 1분기 종합 TOP10 대부분 기획세트. 오아도 히트아이롱+미니 고데기 같은 묶음, 단 처음 보는 브랜드는 1개·낮은 가격 단품으로 먼저(Hyuk: 2개 세트·2배 가격은 장벽) → 세트는 리뷰 쌓인 뒤.

8. 메가와리 첫날 랭킹 진입이 기간 전체 매출 결정 — 전(트래픽 모수 확보)→티저(장바구니 타겟)→본기간(전환) 3단계 예산 배분. 티저 기간 집중 사례: 유입 4배·첫날 매출 40%↑.

9. 싱글원(Qoo10 Single One) 검토 — 큐텐 장바구니/브랜드 페이지 방문자 리타게팅을 메타·라인·틱톡에 집행, 자사 상품 매출만 분리 측정(메타 MPA). 자체 메타 집행 대신 큐텐 전환 추적 가능 채널로 전환. 결제완료 페이지 광고도 상품으로 존재.

10. 리뷰 = 샘플마켓 — 월 500만 응모, 당첨자 2/3가 사진/영상 리뷰, 1/3이 본품 구매. 리뷰 23건인 오아는 밀 제품 1종을 샘플마켓에 먼저 올려 리뷰 축적. 리뷰 콘텐츠는 상세·광고에 재활용.

11. 일본 소구 포인트 조정 — 일본은 습해서 "뽀송·픽싱·밀착" 선호(티르티르). 고데기·브러시 카피에서 "윤광" 대신 "뜬 머리 눌림·습기에도 유지" 쪽. 헤어는 인당 지출이 한국보다 높은 카테고리(Bain).

12. 카테고리 1위 벤치마크 — 가전·PC·게임 카테고리 1위 = 살루니아 스트레이트 고데기. 오아 히트아이롱 경쟁 상대·가격·세트 구성 확인 대상.

13. 상세·광고 문구에 "1위/최고/압도적" 최상급 표현은 출처·기관·조사기간 명기 없으면 경품표시법 위반 — 오아 "리뷰 4.7·○○ 1위" 류 쓸 때 기간·출처 병기.

14. 일본 10~30대는 TV보다 전철/지하철 광고 접촉률 20%p 높음 — 프리온 공항 옥외 검토 시 역/전철 OOH도 비교 대상.

15. 메가데뷔는 현재 뷰티 공식 브랜드샵 위주(이너뷰티 포함, 영업부서 심사) → 뷰티가전 확대 여부 MD에게 문의 가치. 매주 화 10:00 시작, 4브랜드, 30% 쿠폰, 라이브·메일·푸시·호리다시모노 노출+사후 메가키트·VOCE 잡지.

16. 배송 벤치마크 — 큐텐 공식 배송 쉽너지: 한국 출발 2일 내 도어 50%, 3일 83%. KSE/TracX 도쿄 창고와 비교 기준. 무게는 항상 "포장 후 총무게 kg"(실무게의 1.5배 나올 수 있음).

17. 오프라인 바이어는 큐텐 실적을 입점 바로미터로 본다(코스맥스) — 큐텐 매출 10/일 목표는 일본 오프라인·라쿠텐 확장의 레퍼런스로도 가치.
