지금 당장 확인할 것 잘못돼 있으면 돈이 새거나 자격을 잃음

확인사업자번호 미입력 = 수수료에 부가세 10%

  • QSM에 한국 사업자번호가 안 들어가 있으면 판매 수수료에 한국 부가세 10%가 추가로 붙음.
  • oaworld 계정에 입력돼 있는지 확인 필요. (V8)

확인신규 주문은 들어오자마자 발송예정일 입력

  • 新規注文·入金待ち·配送遅延 상태에선 고객이 판매자 승인 없이 즉시 취소 가능 → 그대로 취소율에 잡힘.
  • 発送予定日을 입력하는 순간 임의취소가 막힘. 예정일은 수정 불가.
  • 셀러가 직접 처리하는 취소는 전부 "판매자 사유"(클레임 −3점). 고객 사유 취소는 마이큐텐 요청 유도 또는 큐텐 문의로. (V1·V3)

확인취소율 10%는 "건수"로 희석해야 함

  • 메가와리 자격 = 직전 분기 샵 전체 주문 1건 이상 + 취소율 10% 미만 + 페널티 없음. 상품별이 아니라 아이디 기준.
  • 10건 중 1건 취소면 바로 탈락. 미끼 저단가 상품 5~10개로 분모를 키우고, 재고는 확보분의 80%만 오픈. (V4·V6)

확인배송 지연 페널티는 등록 때 적은 "발송가능일" 기준

  • 일반상품: 입금 +3영업일 메일, +5 경고(−2점), +6 판매·프로모션 정지(31일). 예약상품은 토일 포함이라 더 가혹.
  • 配送管理 그리드에 発送開始日 열을 추가해 보고, 고객 사유 지연은 큐텐 문의로 해제 요청 가능. (V1)

메가와리·메가포 룰 글 요약보다 정확한 버전

룰가격 모니터링 기간과 대상

  • 세일 시작 약 10일 전~3일 전, 1주일. 이 기간 "쿠폰 적용 전 판매가(기본가−할인설정)"를 종료까지 유지.
  • 대상: 판매가·옵션가·배송비 인상, 상품할인 축소, 타임세일·데일리딜·단골할인. 샵쿠폰·포인트는 대상 아님.
  • 위반 시 통지 없이 제외 + 그 회차 재참가 불가. 모니터링 종료~개시 사이엔 가격 변경 가능.
그래서 프리메가(예고 기간) 기획은 샵쿠폰으로 하는 것이 정석. 메가와리 참가 상품엔 공동구매를 동시에 걸 수 없음.

룰메가포는 참가 조건이 없다

  • 메가포(연 8회)는 신규 셀러도 바로 참가. 메가와리만 직전 분기 실적 조건.
  • 메가포 TOP50 평균 2,600엔(메가와리 3,836엔) → 중저가 단품·신상품에 유리. 메가포는 메가와리의 테스트장(2~3배 vs 10~20배).
  • 쿠폰 1·2·3차 발행 첫날/마지막날에 광고 집중. 첫날 랭킹 진입이 기간 매출을 결정. (V5·V7·V8)

룰쿠폰 적용 순서와 배송비

  • 아이템 쿠폰(메가포/메가와리) → 카트 쿠폰(샵쿠폰 + 큐텐 카트쿠폰 동시) → 잔액에 포인트. 메가 쿠폰과 큐텐 카트쿠폰은 중복 불가, 샵쿠폰만 전부 중복.
  • 조건부 쿠폰·메가포 할인·포인트백 전부 배송비 제외 상품가 기준. 카트쿠폰(¥3,000·¥10,000)은 큐텐 전액 부담.
그래서 배송비를 상품가에 녹여 송료무료로 만들고 3,000엔 문턱에 맞출 것. 메가와리 셀러 부담 10%+시스템 이용료 1%+할인지원 수수료 0.5%를 처음 가격 설계에 반영.

룰랭킹은 두 종류

  • 통상 랭킹 = 직근 판매 + 서비스포인트, 1시간 갱신. 세일 중 랭킹 = 누적.
  • 티저 기간엔 사재기 대기로 999/1,999엔 끝수 저가 상품이 통상 랭킹에 쉽게 진입 → 1상품 랭킹 캡처를 서브이미지·SNS에 활용.
  • 리뷰수·팔로워수는 검색순위 직접 요소 아님. 최근 판매 건수가 핵심. (V2·V7)

광고 운용 숫자 강사들이 실제로 쓴 세팅

광고스마트세일즈: 전 상품 깔고 티저 때 올려라

  • 큐텐엔 CPC 광고가 없음. 스마트세일즈는 판매 시에만 수수료(5~30%, 할인 후 결제가 기준). 카트/즐겨찾기 담은 뒤 30일 내 결제분에 과금, 환불 시 광고비도 환불.
  • 경쟁사 상품 페이지 하단 "이런 상품은?"(최대 10)에도 노출. 샵쿠폰 있으면 그 10개 중 클릭 우위.
  • 수수료 11%면 상위 19%. 평시 5~15%, 메가 직전 1주일 20~30%로 올려 적게 팔려도 첫날 랭킹 진입 → 캡처를 상세에 삽입.
  • 캠페인 삭제 불가. 종료일 없음으로 두고 ON/OFF. 1상품 1캠페인. (V2·V3·V5)

광고키워드플러스(플러스전시): 입찰가 순, 선착순

  • 노출 순서는 입찰가 순(실적·리뷰 무관), 동가면 선착순. 전일 19:00~당일 17:50 입찰 → 18:00부터 24시간. 메가와리 첫날은 14:50 마감. 낙찰 실패 시 환불.
  • 빅워드 대신 서제스트 워드가 절반 가격(母の日 ¥1,200~2,500 vs 母の日ギフト ¥1,100~1,300). "韓国+카테고리" 조합은 420회/일에 100~200엔.
  • 1,000엔 메인 키워드보다 100엔 연관 키워드가 효율 좋았던 사례. 200~300엔이면 대부분 낙찰. 100엔 낙찰 가능 키워드는 파워랭크업 대신 플러스전시.
  • 파워랭크업(1일 100엔, 90일 9,000캐시)은 켰으면 끄지 말 것. 주력 2~3개. (V1·V2·V5·V6)

광고광고는 "전략 상품 5~10개"에만

  • 한 상품코드에 옵션을 최대한 몰기(광고비 100엔 ÷ 옵션 10개). 메가포 TOP100 옵션 설정률 89%, 서브이미지 평균 14장, Q-only 43%.
  • 신규 셀러 조합 = 파워랭크업 + 스마트세일즈로 반응 상품 테스트 → Analytics "자세히 보기"에서 광고별·상품별 전환 확인 후 집중. 키워드플러스는 자리 잡은 뒤.
  • AD Analytics(2026.2 오픈, 14일 어트리뷰션)로 광고별 ROAS 확인 가능. 원가 30%면 ROAS 333% 미만은 적자. (V2·V4·V8)

광고타임세일 메뉴가 둘

  • "광고 및 전시"(유료): 프리미엄 0~10시·10~17시 5,000캐시, 17~24시 6,000캐시(PV 최고), 데일리딜 3,000, 스탠더드 1,000. 3,000엔 이하 상품에 적합.
  • "스페셜 할인 관리"(무료): 특집페이지 노출 전무. 팔로워 푸시쿠폰 예고와 묶어야 의미.
  • 유료 타임세일 5일 이상 연속 = 리뷰 시드 최적 수단(강사 의견). 고가 아이론은 검색형 + 공동구매. (V3·V4)

무료 설정 함정 켜놓고도 안 보이는 이유

함정팔로워 한정 샵쿠폰은 2단계

  • 쿠폰 생성(STEP1) 후 "쿠폰 응모 조건"을 기본 "전체" → "내 샵 즐겨찾기 고객만"으로 바꾸고 "초기화"를 눌러 フォローイベント에 연결(STEP2)해야 노출. 미완이 흔한 실수.
  • 메가 때 전원용(¥3,000/¥100)과 별도로 팔로워 한정 고할인(¥3,000/10%) → 팔로워 4.1배 사례. 발급시점+14일 유효로 두면 재발급 불필요.
  • 쿠폰푸시는 주 2회 무료(12월부터), 16상품, 10~22시 30분 단위 예약, 17시 이후·주말 권장. 발행만 한 주 대비 매출 4.6배. (V1·V5·V7)

함정Q스페셜 기획전은 기본값이 "표시 안 함"

  • 경로: 기본정보 → 셀러샵관리 → 기획전관리. 배너 1440×676. "상품상세/셀러샵 표시 = 예"가 기본값이 아니오. 서브테마 미설정이면 상품이 안 뜸. 모바일 이미지는 1:1 또는 세로형 가운데 정렬. 3개월 자동 만료, 검색태그 20개.
  • 메가와리 기간 유입 경로 1위(평시 3위). 샵 메인으로 설정하면 샵쿠폰 버튼 최상단 강조. (V4·V8)

함정검색 요소는 4개뿐

  • 상품명·검색워드(10개)·브랜드·카테고리. 홍보문구는 검색 안 됨. 가격·送料無料·クーポン 문구는 "광고문" 란으로.
  • 브랜드 태그 쓰면 상품명에 브랜드 중복 금지(감점). 영문/가타카나 중복 금지. 상품명 앞 30자에 빅워드.
  • 소분류 "기타" 금지 → 검색량 큰 소분류로 변경해 판매 5배·2.5배 사례. 아날리틱스 검색어를 큐텐 검색창에 넣어 "나만 나오면 번역 오타".
  • 상품명·대표이미지 가이드 "적합(녹색)"은 판매 제한이 아니라 서치포인트 가산점. 상품 진단은 상품조회 → "판매중" 클릭해 1주 PV·판매량. (V1·V3·V4·V5·V6)

함정리뷰 루틴

  • 샘플마켓: 매주 월 0시 오픈, 1회 3상품, 최소 30개, 응모 시 즐겨찾기 필수. 당선자 리뷰율 90%+, 포토 60%+. 대기 2~3개월.
  • 피드백 혜택은 구매확정/텍스트/포토 중 1개만, 25~50P, 설정 이전 주문 미지급. 리뷰 작성 기한 배송완료 후 30일. 판매자 댓글 기능 없음(쪽지로).
  • 저평점 리뷰 주문번호 → "고객 보상" 쿠폰 엑셀 업로드. 리뷰 문구를 썸네일에 반영해 CVR +1%p 사례. 리뷰 작성률 기본 30%(샘플마켓 70%). (V3·V6·V7)
