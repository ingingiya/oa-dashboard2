광고 안내

        1. 전용 게시판
        월 120만원, 부가세 별도 (장기 제휴 별도 문의)

        ﹒업체명으로 단독 게시판을 생성하여 콘텐츠를 게시할 수 있습니다.

        ﹒홍보글 등을 일 최대 2건까지 자유롭게 업로드 하실 수 있습니다.

        ﹒지속적으로 발행하실 콘텐츠가 있으신 경우 적합합니다.

        ﹒꾸준한 글 발행을 통해 자연스러운 브랜드/키워드 노출이 가능합니다.
        추가 혜택

        ﹒첫 포스팅으로 업체 소개글 작성시, 1주일간 전체 공지로 등록 가능합니다.

         (전체 공지는 공지 시점으로부터 1주일간 유지됩니다.)
광고 안내

        2. 대문 풀배너
        월 100만원, 부가세 별도 (장기 제휴 별도 문의)

        ﹒카페 대문에 835 X 135 배너를 업로드합니다.

        ﹒가장 최신 배너가 최상단으로 배치됩니다.

        ﹒클릭시 이동하는 랜딩 페이지는 자유롭게 설정이 가능합니다.


        추가 혜택

        ﹒기간 내 [이벤트&공구&옥션] 게시판에 전체 공지 1회 등록 가능합니다.

         (전체 공지는 공지 시점으로부터 1주일간 유지됩니다.)

        ﹒기간 내 전체 쪽지 1회 발송이 가능합니다.
광고 안내

        3. 타이틀 / 대문 메인 / 모바일 대문 배너
        각 500만원/월, 부가세 별도 (별도 문의)

        타이틀 배너

        ﹒카페 내 어느 페이지로 이동하더라도 상단에 고정 노출됩니다.


        대문 메인 배너

        ﹒대문 전체를 활용함으로써 시각적 효과를 극대화 할 수 있습니다.


        모바일 대문 배너

        ﹒모바일로 진입시 최상단에 노출됩니다.

                                                                 각 50만원/주, 부가세 별도 (월 제휴 별도 문의)

                                                                 상단글 광고

                                                                 하단 배너 광고

        5. 공지 광고
        전체 공지 30만원/주, 부가세 별도

        필독 공지 500만원/주, 부가세 별도

        전체 공지

        ﹒[이벤트&공구&옥션] 게시판에 전체 공지글을 1주간 등록합니다.

        ﹒쪽지와 병행시 할인 가능 (총 50만원, 부가세 별도 / 10만원 할인)


        필독 공지

        ﹒[이벤트&공구&옥션] 게시판에 필독 공지글을 1주간 등록합니다.

        ﹒PC 및 모바일 최상단에 게시글이 고정되어 노출 효과가 뛰어납니다.
