앱 & 웹 실행 첫 화면에 배너 형태로 노출되는 상품입니다.


                                    디바이스        모바일 / PC (APP/WEB)

                                    등록 소재 수     메인 배너 롤링 12개
                                                서브 배너 1개 - 고정형

                                    일 단가        메인 배너 : 50,000원
                                                서브 배너 : 120,000원

                                    일 예상 노출 수   30,000건
홈 메인배너 제작 가이드

                사이즈   가로 680px 세로 400px

                제목    pretendard Bold 72px / 행간 88
                      글자 수 제한 없이 이미지 내 2줄

                내용    pretendard Regular 48px / 행간 70
                      글자 수 제한 없이 이미지 내 1줄

                가이드   - 배너 사방 라운드 처리 (R값 32px)
                      - 배경값을 헥스코드 항목에 추가 입력 
                        (#000000 형식)
                      - 요소 별 마진값 이미지 표기 참고 
                        (1372x800 기준)
홈 서브배너 제작 가이드

                사이즈   가로 343px 세로 70px

                가이드   - 배너 양쪽 여백 96px 권장
                      - 배너 사방 라운드 처리 (R값 32px)

                      예시 배너와 유사하게 디자인할 경우
                      - 제목 pretendard bold 62px 행간 96
                      - 내용 pretendard Regular 48px 행간 96
                      - 좌우 마진 각각 96px
