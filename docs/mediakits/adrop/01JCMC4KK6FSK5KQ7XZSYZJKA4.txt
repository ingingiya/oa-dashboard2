베이비빌리는 임신·출산·육아 전 과정의 엄빠들이 실제로 사용하는 임신·육아 전문 플랫폼이에요.
출산 시기와 육아 단계 기반의 정교한 타겟팅이 가능해, 관심이 가장 높은 순간에 브랜드가 자연스럽게 도달할 수 있어요.
🔁 관심이 최고조일 때 자연스럽게 도달
엄빠들은 ‘지금 나에게 필요한 정보와 제품’을 찾는 흐름 속에서 콘텐츠와 커뮤니티를 이용해요.
베이비빌리는 이 과정에 브랜드를 자연스럽게 연결해 높은 주목도와 수용도를 만듭니다.
🎯 임신·출산·육아 단계 기반 타겟팅
임신 중 / 출산 직후 / 개월 수별 육아맘 등
제품과 가장 잘 맞는 타겟에게 메시지를 정확하게 전달할 수 있어요.
🍼 광고보다 경험 중심의 0원 체험단 구조
단순 노출이 아닌 실제 체험 → 후기 생성 → 자연스러운 공유까지 이어지는 구조로
신뢰도 높은 UGC 확산과 구매 전환을 기대할 수 있어요.

베이비빌리(BabyBilly) 광고 상품 소개서
1. 매체 개요
대한민국 1등 임신/육아 앱
: 임신부 80% 이상이 사용하는 필수 플랫폼입니다.
주요 지표
:
월간 활성 사용자(MAU)
: 40만 명 이상
누적 다운로드
: 220만 회 이상
컨텐츠 부문 체류 시간
: 60분 이상
컨텐츠 누적 조회수
: 1억 회 이상
2. 타겟 오디언스 및 타겟팅
사용자 구성
: 구매력이 높은 3050 여성이 주축이며, 실제 구매 전환 가능성이 높은 유저로 구성되어 있습니다.
인구통계학적 특성
:
연령
: 30대(82.6%), 40대(11.1%), 20대 이하(5.4%)
성별
: 여성 82.9%, 남성 17.1%
상태
: 육아 중(59.4%), 임신 준비 및 임신 중(40.6%)
정교한 타겟팅 옵션
:
지역별
: 서울-경기, 인천, 부산, 충남, 전라도 등
유저 상태별
: 육아, 임신, 임신 준비
임신/육아 시기별
: 임신 주차별(0~9주 등), 아기 월령별(0~11개월, 돌 이후, 2세 이후 등)
타겟팅 적용 시 10~20% 할증이 발생합니다.

: 커뮤니티 목차 및 글 상세에 노출되는 네이티브 광고.

: 2주간 제품 사용 후 설문 진행. 공식 인증 앰블럼 제공(영구 사용 가능).
4. 빌리 라이브 방송
베이비빌리 앱 내 자체 스튜디오와 호스트를 지원하는 라이브 커머스 상품입니다.
패키지 상세
:
기본 송출형 (30만원)
: 본방 송출 + 재송출
기본 운영형 (100만원)
: 본방/재송출 + 스튜디오 + 호스트
프리미엄형 (200만원)
: 운영형 구성 + 카카오 광고 + 메인/쇼핑 팝업 + 베동 배너
공통 제공
: 예고 페이지, 알림받기, 메인배너 노출, 앱 푸시 1회, 결과 리포트
