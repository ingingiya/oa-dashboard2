[미디어믹스] 블랙서클 (Black Circles) 광고상품 소개서
블랙서클은 대한민국 최대 규모의 올인원 자동차용품 B2B 유통 플랫폼으로, 전국 타이어 소매점주와 차량 유지관리 전문가들이 이용하는 No.1 온라인 타이어 비즈니스 플랫폼입니다.
1. 매체 개요 및 주요 지표 (2025.12 기준)
서비스 성격
: No.1 온라인 타이어 B2B 플랫폼
MAU
: 월 평균 약 30,000명 (타이어 실구매 목적의 액티브 유저)
회원 현황
:
소매점 회원: 5,410개소 (전국 B2B 구매 네트워크)
유료 멤버십(블랙패스) 회원: 1,364개소 (재구매율 높은 충성 고객군)
2. 타겟 오디언스 분석
핵심 타깃
: 차량 유지·관리 및 제품 성능에 민감하며 구매력이 높은 실수요층
성별
: 남성 86.6%
연령
: 30~50대 주력
소득
: 연 소득 8천만~1억 이상 64.6%
추천 업종
: 자동차 부품/소모품, 프리미엄 남성 케어, 사업자 대상 솔루션, 건강기능식품/에너지 음료, 산업용 패션(작업복/안전화 등)

4. 상세 광고 상품 안내
① 디스플레이 싱글 커버 (홈 메인 팝업 배너)
지면
: 홈 메인 중간 팝업
과금 방식
: CPP (5주 기준)
타겟팅
: 논타겟팅
특징
: 서비스 접속 시 가장 먼저 노출되는 단독 지면으로 강력한 첫인상 부여
② 디스플레이 임팩트 번들 (고효율 패키지)
과금 방식
: CPP (1주 기준)
구성 유닛
:
홈 최상단 띠 배너
: 사이트 최상단 단독 노출
로그인 헤더 배너
: 로그인 시점 노출로 목적이 뚜렷한 유저 대상
서치바 밴드 배너
: 간편검색 창 하단 위치
PC 사이드 배너 패키지
: 상품 리스트 및 마이페이지 좌측 고정 노출
커뮤니티 영역 배너
: 충성 고객층이 모인 커뮤니티 상단
③ 디스플레이 리치 번들 (브랜딩 패키지)
과금 방식
: CPP (1주 기준)
구성 유닛
:
홈 메인 상단 배너
: 홈 화면 주요 영역 점유
간편검색 논스킵 광고
: 검색 결과 확인 직전 단계 노출
상품 리스트 인라인 배너
: 탐색 리스트 사이 자연스러운 배치
상품 리스트 플로팅 배너
: 스크롤 이동 시 추적 노출
할인율&견적서 논스킵 광고
: 최종 의사결정(견적 확인) 단계 집중 노출
토스트 배너 패키지
: 페이지 이동 시 우측 하단 알림 형태 노출
5. 광고 집행 절차
예약 단계
: 광고 상품, 기간, 타겟팅(국가/소득 등) 선택
정보 입력
: 캠페인 이름, 예산, 광고주 정보 및 링크 입력
결제 및 소재 등록
: 결제 정보 입력 후 최종 확인, 광고 소재(이미지 및 도착 URL) 등록
6. 기타 유의사항
서비스 자체 프로모션 영역(파란색 표시 부분)은 별도 협의 필요
타겟팅 설정 시 일부 상품(싱글 커버, 임팩트 번들)은 논타겟팅으로 진행됨
리치 번들의 경우 멤버십/블랙패스 회원 제외 타겟팅 가능
