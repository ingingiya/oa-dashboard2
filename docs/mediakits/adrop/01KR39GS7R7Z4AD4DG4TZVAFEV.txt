포스텔러(Forceteller) 광고 상품 소개 및 광고 단가표
1. 매체 개요
포스텔러는 정교한 로직 시스템을 바탕으로 사주, 타로, 별자리 등 개인화된 운세 콘텐츠를 제공하는 서비스입니다. 기업의 브랜드 컬러와 이벤트 메시지를 담은 차별화된 리워드 솔루션을 제공하며, 앱 또는 웹 환경에 맞춘 마케팅 이벤트를 지원합니다.
2. 주요 광고 상품
[운세 쿠폰]
특징
: 기프티콘 형태로 제공되는 프리미엄 운세 콘텐츠(최대 6만 자 분량).
제공 형식
: 난수 번호(16자리)가 포함된 LMS 링크 또는 제휴사 앱/웹 내 직접 연동.
콘텐츠
: 약 700개의 프리미엄 운세(사주 페르소나, 타고난 복, 타로 등) 중 선택 가능.
[운세 테스트]
특징
: 유저가 직접 참여하고 자발적으로 공유하는 웹 기반 커스텀 운세 콘텐츠.
유형
:
신규 기획/제작
: 브랜드 톤앤매너에 맞춘 독자적인 테스트 기획 및 제작.
기존 무료 운세 활용
: 포스텔러 보유 운세를 활용한 빠른 제작.
기대 효과
: 단기간 효율적인 비용으로 SNS 바이럴 및 이슈 메이킹.

4. 주요 레퍼런스 (성과)
Kbank
: 신년 운세 100% 무료 제공 및 공유 이벤트. 1차 약 60만 명, 2차 약 72만 명 참여.
페이북
: 출석 체크 리워드로 프리미엄 운세 지급. 쿠폰 이용률 33% 달성.
코카콜라
: 제품 구매 고객 대상 선착순 운세 쿠폰 지급. 쿠폰 이용률 21% 달성.
SBS 신들린 연애
: 사주 신끼 테스트(약 50만 참여), 60갑자 운명패 뽑기(약 180만 참여), 오픈 직후 30일 PV 110만.
티빙 샤먼
: 사주 귀문관살 테스트. 오픈 14일간 PV 약 38만.
자체 바이럴 (도화테스트)
: 누적 참여 인원 약 320만 명.
5. 제작 가이드 및 프로세스
운세 쿠폰 Flow
: 제휴사 웹/앱 내 연동 또는 쿠폰 등록 전용 페이지 제공.
운세 테스트 Flow
: 테스트 진입 → 프로필 입력 → 결과 확인 → 하단 CTA(앱 설치/구매 유도) 연동.
제작 기간
: 운세 테스트의 경우 기획부터 제작까지 약 1~2개월 소요.
커스터마이징
: 테스트 결과 페이지 내 원하는 배너 및 상품 노출, 연결 링크 삽입 가능.
