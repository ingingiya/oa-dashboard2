광고 매체 소개
LINEとYahoo! JAPANを統合した、日本最大級の広告プラットフォームです。
月間約9,800万人が利用するLINEと、約5,400万人が利用するYahoo! JAPANのデータを活用し、日本人口の約8割以上にリーチ可能です。
検索広告・ディスプレイ広告（Yahoo!広告）と、トークリスト・LINE NEWS・LINE VOOMなどに配信可能なLINE広告を組み合わせ、認知から獲得まで幅広いマーケティング施策に対応できます。
日本市場への進出や大規模なリーチ拡大、ターゲティング精度を重視したキャンペーンに最適な広告プラットフォームです。

LINE야후 매체소개서 (2025년 6월 업데이트)
LINE야후는 일본 내 압도적인 이용자 수를 보유한 커뮤니케이션 앱 'LINE'과 종합 인터넷 서비스 'Yahoo! JAPAN'을 중심으로 다양한 마케팅 솔루션을 제공하는 일본 최대 규모의 광고 플랫폼입니다.
1. 매체 개요
미션
: 'WOW'한 라이프 플랫폼을 창조하여 일상에 '!'를 전달함
통합 플랫폼
: 광고 플랫폼 통합과 데이터 솔루션 융합을 통해 인지부터 구매, 팬덤 형성까지의 고객 여정(Customer Journey) 디자인 가능
주요 서비스
: LINE(메신저), Yahoo! JAPAN(포털), LINE NEWS, Yahoo! 뉴스, LINE VOOM, Yahoo! 쇼핑, PayPay 등
2. 타겟 오디언스 및 도달률
일본 인구의 약 80% 이상을 커버하는 압도적인 유저 베이스를 보유하고 있습니다.
이용자 통계
| 구분 | 월간 이용자 수(MAU/ID) | 특징 |
| :--- | :--- | :--- |
|
LINE
| 약 9,800만 명 | 일본 내 압도적 1위 메신저 |
|
Yahoo! JAPAN
| 약 5,400만 명 | 일본 최대 규모의 포털 서비스 |
|
LINE야후 합계
| 연간 약 1억 명 이상 | 일본 인구의 약 80% 이상 이용 |
유저 특성
성별
: 남녀 비율이 비교적 균등함 (스마트폰 기준 여성 52.4%, 남성 47.6%)
연령층
: 10대 이하부터 60대 이상까지 전 연령대를 폭넓게 커버하며, 특히 시니어층과 젊은 층 모두에게 강점이 있음
기기
: 스마트폰과 PC 모두에서 높은 이용률을 보임
3. 주요 광고 및 마케팅 상품
Yahoo! 광고
검색 광고
: Yahoo! JAPAN 검색 결과 상단에 텍스트 링크 형태로 노출
디스플레이 광고(운영형)
: Yahoo! JAPAN 메인 페이지 등에 이미지/동영상 형태로 노출하여 타겟팅 가능
디스플레이 광고(예약형)
: 높은 브랜딩 효과를 목적으로 하는 프리미엄 지면 광고
LINE 광고
노출 지면
: 토크리스트(채팅 목록), LINE NEWS, LINE VOOM(숏폼), 월렛, LINE라시(전단지) 등
특징
: 일상적인 커뮤니케이션 경로에 자연스럽게 노출되어 높은 도달률 기록
기타 마케팅 상품
커뮤니케이션
: LINE 공식 계정, LINE 미니 앱, 프로모션 스티커 등
판촉
: LINE으로 응모, LINE 포인트 AD 등
데이터 활용
: Yahoo! JAPAN 데이터 마케팅 솔루션, LINE DATA SOLUTION
4. 마케팅 강점 및 성과 지표
리치력
: 타 매체로 도달하기 어려운 유저에게도 도달 가능 (LINE야후 독점 리치 비중 약 26.4%)
이용 빈도
: 타 소셜 미디어 대비 압도적인 세션 횟수(월간 이용 횟수) 보유로 브랜드 인지 및 리마인드 효과 탁월
데이터 연동
: 약 2,800만 개의 유저 계정 연동을 통해 플랫폼을 횡단하는 정교한 데이터 분석 및 활용 가능
안전성(JICDAQ 인증)
: 브랜드 세이프티 및 무효 트래픽 대책에 대해 JICDAQ 인증을 취득하여 신뢰할 수 있는 광고 환경 제공
5. 광고 집행 프로세스
Yahoo! 광고
신청
: Yahoo! JAPAN ID 생성 및 광고 신청
설정
: 광고 관리 도구에서 광고 작성, 예산 설정, 지불 정보 입력
게시
: 심사 완료 후 광고 노출 시작 (상시 정지 및 재개 가능)
LINE 광고
계정 개설
: LINE 비즈니스 ID 생성 및 광고 계정 개설
설정
: 미디어, 크리에이티브, 랜딩 페이지 등록
심사
: LINE야후 규정에 따른 게재 가부 심사
개시
: 등록된 일시에 광고 게재 시작
6. 품질 및 정책
DE&I 추진
: 다양성, 공평성, 포용성을 존중하는 마케팅 활동 장려 및 관련 유저 보이스 정보 제공
품질 관리
: 기계 학습과 인력을 결합한 광고 심사 체계 구축, 정기적인 투명성 리포트 공개
