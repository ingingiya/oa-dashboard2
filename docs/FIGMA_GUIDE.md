# 상세페이지 피그마 템플릿 가이드 (디자이너용)

디자인이 그대로 상세페이지 코드가 됩니다. 규칙은 사실상 하나 — **바뀔 자리에 `{{경로}}` 이름 붙이고 눈알 끄기.**

## 1. 섹션 프레임

- 상세페이지 한 덩어리(후킹, USP, 스펙표…) = 최상위 프레임 하나
- 프레임 이름은 `sec:` 접두사 필수 — 예: `sec:후킹`, `sec:USP`, `sec:CTA`
- 폭은 **860px** 고정 권장 (스마트스토어 기준), 높이는 자유
- 프레임의 위→아래 순서(Y좌표)대로 상세페이지에 이어 붙습니다

## 2. 데이터가 들어갈 자리 (플레이스홀더)

제품마다 바뀌는 텍스트/이미지 자리에 레이어를 만들고:

1. **레이어 이름을 `{{경로}}`로** — 제품 JSON의 경로 그대로
   - 텍스트: `{{hook.headline}}`, `{{hook.sub}}`, `{{usp[0].headline}}`, `{{tagline}}`
   - 이미지(사각형): `{{hook.image}}`, `{{usp[0].image}}`, `{{cta.image}}`
2. **눈알을 꺼서 숨김** — 숨겨야 배경 PNG에 안 찍히고, 위치·폰트 정보만 추출됩니다
3. 텍스트 레이어는 실제 쓸 폰트/크기/색/정렬로 스타일링해두세요 — 그 스타일 그대로 렌더됩니다

고정 문구(제품 바뀌어도 안 변하는 장식·타이틀)는 그냥 보이게 두면 배경에 포함됩니다.

## 3. 주의

- 카피가 시안보다 길면 박스 아래로 흐릅니다 → **최대 길이 기준으로 박스를 잡아주세요**
- `{{}}` 레이어는 프레임 안 어디에 중첩돼 있어도 인식됩니다
- 이미지 자리 사각형에 코너 라운드를 주면 그대로 적용됩니다

## 4. 반영 방법

디자인 수정 → 대시보드 **상세페이지 생성기 → "피그마 동기화"에 파일 링크 넣고 딸깍**. 끝.
(개발자 개입 없음 — 동기화하면 다음 렌더부터 새 디자인 적용)

## 경로 치트시트 (product JSON 구조)

| 경로 | 내용 |
|---|---|
| `productName` | 제품명 |
| `hook.headline` / `hook.sub` / `hook.image` | 후킹 헤드라인/서브/이미지 |
| `usp[0~2].headline` / `.desc` / `.image` | USP 3종 |
| `scene.headline` / `scene.images[0~1]` | 사용씬 |
| `cert.headline` / `cert.items[n]` / `cert.image` | 인증/실험 |
| `faq[n].q` / `faq[n].a` | FAQ |
| `cta.headline` / `cta.image` / `tagline` | CTA |
