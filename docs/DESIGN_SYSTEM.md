# OA 상세페이지 디자인 시스템 (디자이너 원본 추출)

> 소스: 오아 에어스트레이트(ODRY-012) 상세페이지 35조각 + 통짜 2종 분석 (2026-08).
> 이미용가전(뷰티) 톤 기준. 추가 제품 상세페이지 입수 시 이 문서를 보강할 것.
> 용도: /api/detail/copy 카피 구조, 렌더 HTML 템플릿, 나노바나나 컷 연출 프롬프트의 기준.

## 1. 섹션 구조 (위→아래 순서)

1. **인트로 히어로** — 상단 알약 뱃지 로고 → 영문 필기체 로고(대형) → 한글 제품명. 아래 모델 히어로컷(제품 파지), 우하단에 제품 팩샷 컷아웃 삽입
2. **컨셉 카피** — 2~3줄. 핵심 구절만 흰 박스 하이라이트 + 컬러 볼드 ("드라이부터 고데기까지" / "하나로 완성하는 스타일")
3. **핵심 기능 GIF 2연속** — 폴라로이드/스프링노트 프레임 안에 시연 GIF + 한 줄 캡션 (키워드만 볼드)
4. **해시태그 히어로** — 모델컷 위에 #기능명 알약 뱃지 3~4개 흩뿌림 (#듀얼모드 #적외선+음이온케어)
5. **문제제기 → 기술 브랜딩 카드** — 질문형 카피 → 흰 카드에 기술명(노랑 형광펜 하이라이트) + 3중 케어식 요약
6. **비교 선언** — "같은 머리, 다른 결과" 대형 카피 → before/after 사진 → 일반 vs 오아 X/O 비교표 (가운데 VS 원형 뱃지, 오아 쪽 컬러 강조)
7. **아이콘 스펙 그리드 2×3** — 라인 아이콘 + 볼드 키워드/수치 (듀얼 모드 · 97,000RPM · 적외선 · 음이온 · 자동 청소)
8. **모드 설명** — "mode 01." 라벨 + 흰 박스 모드명 + 설명 3줄 + GIF(도면 일러스트 + 실사 반반, OPEN/CLOSE 텍스트)
9. **Point 01~05 반복 모듈** (USP 코어):
   - 알약 뱃지 "Point 0N" → 서브카피 한 줄 → **대형 그라데이션 타이틀** → 제품 연출컷(광선/파티클 효과) → 라인 아이콘 3종 요약(이름+한 줄) → 흰 박스 보조 카피 → 실험/비교 GIF(기존 vs 오아 라벨 알약)
   - 수치는 초대형 숫자 + 단위 작게 (97,000RPM), 보조 수치는 형광펜 (1cm³당 500만 개)
10. **조작 UI 설명** — 버튼별 카드 (아이콘 + 설정 항목 + 제품 클로즈업 세로컷)
11. **스타일링 팁 4종** — 노랑 박스 제목 → 모델컷 or before/after → "Styling Tip!" 핑크 라벨 → 팁 2줄
12. **안전 기능 체커보드** — 2열 그리드, 사진/텍스트 교차 배치 (자동 대기모드·잠금·과열 차단·필터 청소)
13. **Color Option** — 그라데이션 배경 + 영문 필기체 제목, 컬러별 연출컷 + 컬러명(영문 대형)
14. **인증서** — 흰 배경에 KC 서류 스캔 2장
15. **제품정보 표** — 라벨/값 2열, 얇은 구분선 (제품명·모델명·크기·무게·전압·재질·KC번호)
16. **패키지 구성 · 주의사항** — 플레인 리스트

## 2. 디자인 토큰

- **컬러**: 베이스 연핑크(#FBE4EA 계열) / 포인트 핑크(#F2739B 계열, 그라데이션 타이틀) / 하이라이트 노랑(#FFF3C4 형광펜·박스) / 흰 카드 / 본문 잉크 #444. 배경은 연핑크↔흰색↔그라데이션을 섹션마다 교차해 리듬 생성
  - ※ 제품 브랜드 컬러에 맞춰 교체 (뷰티=핑크, 리빙/테크는 제품 키컬러)
- **타이포**: 영문 세리프 이탤릭(로고·무드 타이틀, Air Straight/One pass 류) + 한글 고딕. 위계 = 뱃지(12~14) < 서브카피(18) < 본문(15, 회색) < 섹션 타이틀(32~40, 컬러/그라데이션) < 초대형 수치(60+)
- **정렬**: 전부 중앙 정렬, 본문은 2~3줄 단위로 끊음
- **시그니처 장치**:
  - 알약(pill) 뱃지 — 섹션 라벨(Point 0N), 해시태그, before/after 라벨(before=흰, 제품명=핑크)
  - 흰 박스 하이라이트 — 핵심 구절/모드명을 박스로 띄움
  - 노랑 형광펜 — 기술명·수치 밑줄 하이라이트
  - 폴라로이드/스프링노트 프레임 — GIF 시연 컷
  - X/O 비교표 + VS 원형 뱃지
  - 라인 아이콘(포인트 컬러 단색) 3종 세트
- **여백**: 섹션 간 대형 여백(본문 폭 860px 기준 120px+), 답답하게 붙이지 않음

## 3. GIF/모션 사용 규칙 (모션 레퍼런스 탭과 연결)

- 기능 전환 시연: 제품 조작 실사 GIF (OPEN/CLOSE, 모드 전환)
- 실험 비교: 기존 제품 vs 오아 나란히 (직진풍 텐셀, 머릿결 낙하)
- 결과 증명: before/after, 머릿결/피부 클로즈업 루프
- 위치: 섹션 3(도입 2연속), 섹션 8~9(포인트마다 1개), 섹션 11(팁)

## 4. 카피 톤

- 문제제기는 질문형 ("~루틴인지 확인해 보셨나요?")
- 기능은 [조건, 결과] 리듬 ("열어서, 집으면 스타일링! / 닫아서, 말리면 쾌속 건조!")
- 수치 먼저, 설명 나중. 한 문장 = 한 줄, 최대 3줄
- 비교는 항상 "기존 ○○" vs "오아 제품명" 명시
